# DayMood - Mobile Frontend

## Description

DayMood is a mobile app focused on emotional well-being that allows users to record, monitor, and analyze their daily emotions and habits. This repository contains the mobile app’s frontend, developed for Android using Kotlin and Jetpack Compose.

The project emerged in response to the growing need for accessible digital tools that facilitate mental health management, especially among young people, by transforming emotional experiences into structured, analyzable data.

## The problem

Currently, many people struggle with:

* Identifying and understanding their emotions
* Consistently tracking their habits
* Detecting emotional patterns over time
* Accessing structured self-care tools
* Feeling supported in their emotional journey

Despite the growth of digital apps, there is a lack of solutions that integrate tracking, analysis, and support into a single platform.

## Proposed Solution

DayMood offers a mobile app that integrates:

* Daily tracking of emotions and habits
* Customization of emotions using personal content
* Viewing of weekly statistics
* A forum segmented by age and categories
* Assessment of emotional progress using Likert-scale surveys

The mobile frontend is the layer responsible for direct interaction with the user, providing an intuitive, accessible interface focused on the user experience.

## Key Features

### Daily Log

Allows the user to select an emotion and one or more habits to generate a structured log of the day.

### Emotion Customization

The user can create custom emotions, including name, category, and image.

### Weekly Statistics

Visualization of emotional trends based on the logs recorded.

### Forum
A space for interaction where users can post and comment within categories and age ranges.

### Surveys
A system based on the Likert scale to measure dimensions of emotional intelligence.

## Legal and privacy considerations
The system is designed in accordance with regulations related to:

* Personal data protection
* Informed consent
* Use of sensitive data (emotions and habits)
* ARCO rights (access, rectification, erasure, and objection)

Furthermore, the application:

* Does not perform clinical diagnoses
* Does not replace professional psychological care
* Uses data solely for personal monitoring and analysis purposes
